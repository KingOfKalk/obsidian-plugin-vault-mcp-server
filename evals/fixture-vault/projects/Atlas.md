# Project Atlas

Groundwater sensing pilot along the upper river basin. #project #hydrology

## Goals

- Install twelve pressure sensors before the spring melt.
- Publish a weekly summary for the regional water board.

Led by [[Mira Chen]], with data pipelines from [[Tomas Okafor]].
